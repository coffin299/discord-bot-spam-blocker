機能

実装されている保護機能の概要です。

スパムブロック

enable_spam_filter などで個別に切り替えできます。

  • BOT許可リスト

    allowed_bots が空なら全BOT許可。IDがあるときだけリスト外を削除／参加KICKします。

  • リンク・招待・NGワード

    Discord招待、疑わしいURL（2026向けパターン）、詐欺定型フレーズを検知して削除します。

  • メンション・絵文字・大文字

    マスメンションや過度なメンション／絵文字／英字大文字を制限できます。繰り返し文字ブロックは入れていません。

  • 監視範囲

    サーバー・チャンネルを絞れます。空なら参加ギルド／全チャンネルが対象です。

ハニーポット

ハックされたユーザーが罠チャンネルに書き込む前提。既定はKICKです。

  • 即時処罰

    除外リスト外の投稿1通で作動。理由欄は「ハニーポット作動」。

  • 再加入ループ対策

    max_kick_before_ban 回までKICKを許容し、超過でBANします。

  • メッセージ掃除

    対象ユーザーの既存メッセージを可能な範囲で削除します。

  • 除外

    admin_ids / whitelisted_users / allowed_bots / honeypot.whitelist_ids と自BOT。

アンチニュークとロックダウン

破壊行為の短期バーストを検知します。

  • 検知対象

    大量BAN／KICK、チャンネル作成・削除、ロール削除、Webhook更新。

  • 隔離

    実行者をタイムアウト、または危険ロールの剥奪（設定で選択）。

  • 緊急ロックダウン

    nuke_lockdown_enabled が true のときのみ。@everyone の送信等を一時制限し、完了後に admin_ids へDMします。

  • 操作権限

    ロックダウン開始・解除は Discord管理者ではなく admin_ids のみです。

ロックダウンは強力です。本番ではテスト後に有効化してください。既定はオフです。

ハイブリッドコマンド

同じ操作をプレフィックスとスラッシュのどちらからでも実行できます。

  • プレフィックス

    !!!add_bot のように !!! 付きで実行します。

  • スラッシュ

    /add_bot のように Discord のスラッシュ UI から実行します。

  • 招待スコープ

    スラッシュを使うには OAuth2 で applications.commands を含めて招待してください。

  • 反映タイミング

    BOT起動時にコマンドを同期します。初回は Discord 側の反映に数分かかることがあります。
