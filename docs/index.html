Discord Spam Blocker

未許可BOT・詐欺リンク・荒らしに対して、スパム検知・ハニーポット・アンチニュークでサーバーを守るBOTです。

セットアップ リポジトリ

起動例

pip install -r requirements.txt
python main.py

初回起動で config.yaml が生成されます。

何ができるか

音楽再生やLLM歓迎メッセージは含みません。モデレーションに絞っています。

  • スパムブロック

    未許可BOTの投稿削除、招待リンク・疑わしいURL・NGワードなどを検知します。

  • ハニーポット

    罠チャンネルへの投稿でKICK（既定）。再加入を繰り返すとBANします。

  • アンチニューク

    短時間の大量キック／バンやチャンネル破壊を検知し、実行者を隔離します。

  • 緊急ロックダウン

    設定で有効化した場合のみ。admin_ids が手動開始・解除できます。

はじめに

導入の流れはセットアップページにまとめています。

  1. リポジトリを取得し、依存関係をインストールする
  2. Discord Developer Portal でBOTを作成し、Intentと権限を設定する
  3. config.yaml にトークンと admin_ids を書き、起動する
