コマンド

すべての管理コマンドはハイブリッドです。プレフィックス !!! とスラッシュ / のどちらでも同じ操作ができます。招待時は applications.commands スコープが必要です。

使い方

例: BOT を許可リストに追加する場合。

!!!add_bot 123456789012345678
/add_bot bot_id:123456789012345678
スラッシュが一覧に出ないときは、BOTを再起動し、数分待つかクライアントを再起動してください。

Discord 管理者向け

サーバーの管理者権限が必要です。下はプレフィックス表記です。スラッシュでも同名で呼べます。

BOT許可リスト

  • !!!add_bot / /add_bot — 許可リストへ追加
  • !!!remove_bot / /remove_bot — 削除
  • !!!list_bots / /list_bots — 一覧（空＝全BOT許可）

監視チャンネル

  • !!!add_channel / /add_channel
  • !!!remove_channel / /remove_channel
  • !!!list_channels / /list_channels

NGワード

  • !!!add_keyword / /add_keyword
  • !!!remove_keyword / /remove_keyword
  • !!!list_keywords / /list_keywords

その他

  • !!!add_guild / /add_guild — 監視サーバー追加
  • !!!reload_config / /reload_config — 設定再読込
  • !!!status / /status — 主要スイッチの状態

admin_ids のみ

config の admin_ids に書いたユーザーだけが使えます。nuke_lockdown_enabled: true が必要です。

  • !!!lockdown / /lockdown — 緊急ロックダウン開始
  • !!!unlock_lockdown / /unlock_lockdown — 解除
  • !!!nuke_status / /nuke_status — 検知件数とロックダウン状態
ロックダウン完了後、admin_ids へDMが送られます（相手のDM設定次第）。失敗時はログチャンネルへ出ます。
