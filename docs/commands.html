コマンド

プレフィックスは !!! です。

Discord 管理者向け

サーバーの管理者権限が必要です。

BOT許可リスト

  • !!!add_bot <BOT_ID> — 許可リストへ追加
  • !!!remove_bot <BOT_ID> — 削除
  • !!!list_bots — 一覧（空＝全BOT許可）

監視チャンネル

  • !!!add_channel <CHANNEL_ID>
  • !!!remove_channel <CHANNEL_ID>
  • !!!list_channels

NGワード

  • !!!add_keyword <単語>
  • !!!remove_keyword <単語>
  • !!!list_keywords

その他

  • !!!add_guild <GUILD_ID> — 監視サーバー追加
  • !!!reload_config — 設定再読込
  • !!!status — 主要スイッチの状態

admin_ids のみ

config の admin_ids に書いたユーザーだけが使えます。nuke_lockdown_enabled: true が必要です。

  • !!!lockdown — 緊急ロックダウン開始
  • !!!unlock_lockdown — 解除
  • !!!nuke_status — 検知件数とロックダウン状態
ロックダウン完了後、admin_ids へDMが送られます（相手のDM設定次第）。失敗時はログチャンネルへ出ます。
